Размер группы ограничен 2-4 находками, чтобы исчерпание лимита посреди сессии стоило минимум. Порядок групп — по риску (safety → потеря данных → чистка → документация), выбран пользователем из трёх вариантов. Три находки, требующие продуктового решения, а не фикса (LOG-4 персистентность `mealTypes`, DEAD-4 поведение при удалении категории, DOC-5 шеринг), по решению пользователя вынесены в финальную группу 12 — так 36 бесспорных находок закрываются без единой остановки на вопрос. Правило «одна находка = один коммит» из `CLAUDE.md` сохраняется внутри групп: группа — единица сессии, а не коммита. Для возобновления работы в новой сессии в начало файла отчёта добавлена таблица «Прогресс проработки» на 13 строк — без неё пришлось бы сканировать все 39 находок в поисках непомеченных.
